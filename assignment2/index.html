Section 1

Project Overview

This RPA project automates the end-to-end invoice processing workflow — from email receipt to system entry — eliminating manual data entry and reducing processing errors.

📧

Trigger

Incoming invoice emails with PDF attachments

🤖

Automation

Extract, validate, and route invoice data automatically

✅

Outcome

Invoice recorded in accounting system + confirmation sent

👤

Human Step

Manager approval for invoices exceeding $5,000

Current State (As-Is Process)

Accounts payable staff manually monitor a shared email inbox, download invoice attachments, open each PDF to read the invoice number, vendor name, date, and amount, then manually key this data into the accounting software. Invoices above $5,000 are printed and walked to the finance manager for a wet signature before re-entry. The entire cycle averages 45–60 minutes per invoice and is highly prone to data entry errors, duplications, and delays.

Section 4

Process Design Document (PDD)

Formal documentation of the automation scope, data flows, exception handling, and success criteria for this RPA project.

📋

Process Overview

The Invoice Processing Automation project targets the accounts payable department's manual invoice handling workflow. Currently, employees spend 45–60 minutes per invoice performing repetitive tasks: monitoring a shared inbox, downloading PDF attachments, manually reading and keying invoice fields into the accounting system, and emailing confirmations.

The RPA solution will deploy an unattended UiPath robot that continuously monitors the inbox, extracts structured data using AI-powered OCR, applies business rules (e.g., approval thresholds), and completes system entry — reducing cycle time to under 3 minutes per invoice.

🎯

Automation Scope

✅ Included

  • Email inbox monitoring
  • PDF attachment download
  • Data extraction (OCR)
  • Field validation
  • Approval routing (>$5K)
  • Accounting system entry
  • Database record storage
  • Confirmation emails
  • Audit log updates

⚠️ Excluded

  • Manager approval decision
  • Vendor dispute handling
  • Invoice creation
  • Partial payment splits
  • Non-English invoices
  • Handwritten invoices
↔️

Input / Output Specifications

Inputs

  • Invoice email (IMAP/Exchange)
  • PDF invoice attachment
  • Approval threshold config
  • Accounting system credentials

Outputs

  • Invoice record in ERP/accounting
  • Vendor confirmation email
  • Database entry (invoice archive)
  • Audit log entry
  • Exception alerts (if error)

Data formats: Input — PDF, MIME email. Output — JSON to ERP API, SMTP email, SQL database row, CSV audit log.

⚠️

Exception Handling

Missing Attachment: Robot flags email, sends alert to AP team, skips processing.
OCR Extraction Failure: Invoice routed to manual queue with original file attached.
Validation Error: Missing PO number, duplicate invoice detected — logged and escalated.
Accounting System Down: Robot retries 3× with 5-minute intervals; notifies admin if still unavailable.
Approval Timeout: If manager does not respond within 48 hours, escalate to finance director.

All exceptions are logged to the audit table with timestamp, error type, and invoice reference.

Section 5

RPA Workflow Implementation

Step-by-step strategy for translating this process design into a live UiPath automation deployment.

1

Development Environment Setup

  • Install UiPath Studio Community Edition (free)
  • Connect to UiPath Orchestrator (cloud-hosted)
  • Create a new Process project in Studio
  • Install packages: Mail Activities, PDF Activities, Document Understanding
  • Configure credentials in Orchestrator Assets (no hardcoded passwords)
2

Workflow Configuration

  • Trigger: Orchestrator time-based trigger every 15 minutes OR email arrival event
  • Variables: InvoiceAmount (Double), VendorName (String), InvoiceNumber (String), ApprovalStatus (Boolean)
  • Config file: Excel/JSON config for approval thresholds, retry counts, email addresses
  • Use Flowchart activity for main process logic with branching
3

System Integration

  • Email: Use Get IMAP Mail Messages or Get Outlook Mail Messages activity
  • PDF: UiPath Document Understanding + AI Center for intelligent OCR
  • Accounting System: UI Automation (scraping) or REST API integration if available
  • Database: Execute NonQuery activity with parameterized SQL INSERT
  • Approval: Send Outlook/Teams message with approve/reject links
4

Testing & Validation Strategy

  • Unit Tests: Test each activity in isolation using UiPath Test Suite
  • Integration Test: End-to-end run with sample invoices (5 valid + 5 exception cases)
  • UAT: AP team validates outputs against manually processed invoices
  • Parallel Run: Run bot alongside manual process for 2 weeks to compare results
  • Sign-off: Finance manager approves before go-live
